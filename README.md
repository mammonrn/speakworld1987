# SpeakWorld — Telegram Voice Translation Bot

โครงเริ่มต้นของ Telegram bot ที่เขียนด้วย **Node.js + [Telegraf](https://telegraf.js.org/)**

## เป้าหมายของโปรเจกต์

เป้าหมายสุดท้ายคือบอทที่ทำหน้าที่เป็น **ล่ามเสียงสองทาง**:

1. ผู้ใช้พูดภาษาไทยส่งเป็น voice message เข้ามาใน Telegram
2. บอทถอดเสียงเป็นข้อความ (Speech-to-Text)
3. แปลเป็นภาษาปลายทางที่ผู้ใช้เลือก — **คาซัค / อังกฤษ / จีน / พม่า**
4. เมื่ออีกฝ่ายตอบกลับมาด้วยภาษานั้น บอทจะ **แปลกลับเป็นภาษาไทยอัตโนมัติ**

ตอนนี้ยังอยู่ในขั้น "โครงโปรเจกต์" — ส่วน STT และ Translation API ยังไม่ถูกเชื่อมต่อ

## สถานะปัจจุบัน

| ฟีเจอร์ | สถานะ |
| --- | --- |
| `/start` ทักทายภาษาไทย | ✅ ใช้งานได้ |
| รับ voice message แล้วตอบรับ | ✅ ใช้งานได้ (เป็น placeholder) |
| เลือกภาษาปลายทาง | ⏳ ยังไม่พัฒนา |
| ถอดเสียง (STT) | ⏳ ยังไม่พัฒนา |
| แปลภาษา + แปลกลับ | ⏳ ยังไม่พัฒนา |

เมื่อส่งข้อความเสียงเข้ามาตอนนี้ บอทจะตอบว่า
`ได้รับข้อความเสียงแล้ว (ยังไม่เปิดใช้งานการแปล)`

## โครงสร้างไฟล์

```
.
├── index.js                      # จุดเริ่มต้น: สร้าง bot, ลงทะเบียน handler, launch
├── package.json
├── .env.example                  # ตัวอย่างตัวแปรสภาพแวดล้อม (ห้ามใส่ค่าจริง)
├── .gitignore                    # กัน node_modules/ และ .env
└── src
    ├── config.js                 # อ่านค่าจาก .env และตรวจสอบความถูกต้อง
    └── handlers
        ├── index.js              # รวบรวมและลงทะเบียน handler ทั้งหมด
        ├── start.js              # คำสั่ง /start
        ├── voice.js              # รับ voice message (placeholder รอ STT)
        ├── language-select.js    # (โครงว่าง) เลือกภาษาปลายทาง
        └── translate.js          # (โครงว่าง) แปลภาษาไป-กลับ
```

การเพิ่มฟีเจอร์ใหม่ทำได้โดยสร้างไฟล์ใน `src/handlers/` ที่ export ฟังก์ชัน
`register(bot)` แล้วเพิ่มเข้าไปในลิสต์ `handlers` ใน `src/handlers/index.js`

## การติดตั้งและใช้งาน

ต้องใช้ Node.js เวอร์ชัน 18 ขึ้นไป

```bash
# 1. ติดตั้ง dependencies
npm install

# 2. สร้างไฟล์ .env จากตัวอย่าง
cp .env.example .env

# 3. ใส่ token ที่ได้จาก @BotFather ลงในไฟล์ .env
#    TELEGRAM_BOT_TOKEN=123456:ABC-DEF...

# 4. รันบอท
npm start
```

ระหว่างพัฒนาใช้ `npm run dev` เพื่อให้ Node รีสตาร์ทอัตโนมัติเมื่อไฟล์เปลี่ยน

## ตัวแปรสภาพแวดล้อม

| ตัวแปร | จำเป็น | คำอธิบาย |
| --- | --- | --- |
| `TELEGRAM_BOT_TOKEN` | ✅ | Token ของบอทจาก [@BotFather](https://t.me/BotFather) |

## ความปลอดภัย

- **ห้าม** commit ไฟล์ `.env` หรือใส่ token / API key จริงลงในโค้ดเด็ดขาด
- `.gitignore` กัน `.env` และ `node_modules/` ไว้แล้ว
- หาก token หลุดออกไป ให้ revoke ทันทีผ่าน `/revoke` ที่ @BotFather
