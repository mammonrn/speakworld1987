# SpeakWorld — Telegram Voice Translation Bot

โครงเริ่มต้นของ Telegram bot ที่เขียนด้วย **Node.js + [Telegraf](https://telegraf.js.org/)**

## เป้าหมายของโปรเจกต์

เป้าหมายสุดท้ายคือบอทที่ทำหน้าที่เป็น **ล่ามเสียงสองทาง**:

1. ผู้ใช้พูดภาษาไทยส่งเป็น voice message เข้ามาใน Telegram
2. บอทถอดเสียงเป็นข้อความ (Speech-to-Text)
3. แปลเป็นภาษาปลายทางที่ผู้ใช้เลือก — **คาซัค / อังกฤษ / จีน / พม่า**
4. เมื่ออีกฝ่ายตอบกลับมาด้วยภาษานั้น บอทจะ **แปลกลับเป็นภาษาไทยอัตโนมัติ**

## สถานะปัจจุบัน

| ฟีเจอร์ | สถานะ |
| --- | --- |
| `/start` ทักทายภาษาไทย | ✅ ใช้งานได้ |
| เลือกภาษาปลายทาง (inline keyboard) + `/cl` | ✅ ใช้งานได้ |
| react ❤ ทันทีที่ได้รับข้อความเสียง | ✅ ใช้งานได้ |
| ถอดเสียงด้วย OpenAI Whisper (`whisper-1`) | ✅ ใช้งานได้ |
| แปลไทย → ภาษาปลายทาง | ✅ ใช้งานได้ |
| แปลกลับเป็นไทยอัตโนมัติ | ✅ ใช้งานได้ |

## การทำงาน

**ขาไป — ผู้ใช้ส่งข้อความเสียงภาษาไทย**

1. บอท react ข้อความเสียงด้วย ❤ ทันที เป็นการบอกว่าได้รับแล้วโดยไม่ต้องรอผลแปล
2. ครั้งแรกของแต่ละแชท บอทจะถามภาษาปลายทางด้วยปุ่ม
   🇰🇿 คาซัค | 🇬🇧 อังกฤษ | 🇨🇳 จีน | 🇲🇲 พม่า แล้วจำไว้ต่อ `chat_id`
3. ดาวน์โหลดไฟล์เสียงจาก Telegram → ส่งเข้า Whisper → ได้ข้อความ
4. ส่งข้อความเข้า Google Cloud Translation → ตอบกลับ 2 บรรทัด

ขั้นที่ 3 จะแนบ `prompt` เป็นรายชื่อสถานที่ที่เกี่ยวข้องกับภาษาปลายทางของแชทนั้น
(จาก `config/whisper-vocabulary.js`) เพื่อช่วยให้ Whisper ถอดชื่อเฉพาะได้แม่นขึ้น
เช่นแชทที่ตั้งภาษาพม่าจะได้ชุด "ท่าขี้เหล็ก เมียวดี ย่างกุ้ง …" ส่วนแชทภาษาจีน
จะได้ชุดสถานที่ในไทยที่นักท่องเที่ยวจีนถามถึงแทน — ไม่ใช่ส่งรวมกันทุกภาษา
แชทที่ยังไม่ได้ตั้งภาษาจะใช้ชุดกลางที่สั้นกว่า

```
Сәлеметсіз бе
ความหมาย: สวัสดีครับ สบายดีไหม
```

บรรทัด `ความหมาย:` คือ transcript ภาษาไทยจาก Whisper โดยตรง ไม่ได้เรียก AI เพิ่ม

**ขากลับ — อีกฝ่ายตอบกลับมา**

ทุกข้อความที่เข้ามา (พิมพ์หรือเสียง) จะถูกตรวจภาษา ถ้าตรงกับภาษาปลายทางที่ตั้งไว้
บอทจะแปลกลับเป็นไทยให้อัตโนมัติ ข้อความเสียงจะผ่าน Whisper แบบ auto-detect ภาษาก่อน
(ไม่ล็อกเป็นไทย)

### ตรวจภาษาพร้อมแปลในคำขอเดียว

Google คืน `detectedSourceLanguage` มาพร้อมผลแปลอยู่แล้วเมื่อไม่ระบุ `source`
บอทจึงไม่ยิง detect endpoint แยกอีกคำขอ แต่ต้องเลือกภาษาปลายทางก่อนจะรู้ผลตรวจ
จึงเดาจากเส้นทางที่ข้อความเข้ามา — เสียงมักเป็นคนไทยพูด ส่วนข้อความพิมพ์ที่เราสนใจ
คือฝั่งตรงข้ามตอบกลับ:

| ข้อความเข้ามา | คำขอแรกแปลไป | จำนวนคำขอ (เดิม → ใหม่) |
| --- | --- | --- |
| เสียงภาษาไทย | ภาษาปลายทาง | 2 → **1** |
| เสียงภาษาปลายทาง | ภาษาปลายทาง (เดาผิด) | 2 → 2 |
| พิมพ์ภาษาปลายทาง | ไทย | 2 → **1** |
| พิมพ์ภาษาไทย (เงียบ) | ไทย | 1 → 1 |

เดาถูกจบใน 1 คำขอ เดาผิดค่อยยิงอีกคำขอเพื่อแปลอีกทาง ซึ่งเท่ากับจำนวนเดิมที่ต้อง
ยิง detect ก่อนเสมอ — ไม่มีกรณีไหนแย่ลง ผลลัพธ์ที่ผู้ใช้เห็นเหมือนเดิมทุกกรณี
และภาษาที่ตรวจได้ยังถูกเขียนลง log ทุกครั้งเพื่อให้ไล่ปัญหาได้

ข้อความ **พิมพ์** ภาษาไทยจะถูกปล่อยผ่านเงียบๆ เพื่อไม่ให้บอทตอบแทรกทุกประโยค
ที่คนไทยคุยกันในแชท — การแปลขาไปเริ่มจากข้อความเสียงเท่านั้น

## ความเร็วและความเสถียร

ระหว่างประมวลผลข้อความเสียง บอทจะขึ้นสถานะ "กำลังพิมพ์" ทันทีหลัง react ❤
แล้วส่งซ้ำทุก 4 วินาทีจนกว่าจะตอบกลับ เพราะ Telegram ให้สถานะหมดอายุเองที่ราว 5 วินาที
งานที่ใช้เวลานานกว่านั้นจึงต้องต่ออายุเอง ไม่งั้นแชทจะดูเงียบทั้งที่บอทยังทำงานอยู่

ทุกการยิง API (ดาวน์โหลดไฟล์เสียง, Whisper, Google Translate) จะ**ลองใหม่อัตโนมัติ 1 ครั้ง**
เมื่อเจอ timeout หรือปัญหาเครือข่าย (`ECONNRESET`, `ECONNREFUSED`, ฯลฯ) โดยหน่วง 1 วินาทีก่อนลอง
ส่วนกรณีที่ API ตอบกลับมาแล้วด้วยสถานะผิดพลาด (4xx/5xx) จะไม่ลองซ้ำ เพราะยิงใหม่ก็ได้คำตอบเดิม
เสียเวลาผู้ใช้เปล่าๆ

| ค่า | ปัจจุบัน |
| --- | --- |
| timeout ของ Whisper | 75 วินาที |
| timeout ของ Google Translate | 15 วินาที |
| timeout ของการดาวน์โหลดไฟล์เสียง | 30 วินาที |
| จำนวนครั้งที่ยิงรวม | 2 (ครั้งแรก + ลองใหม่ 1) |

หากล้มเหลวจนครบทุกครั้ง บอทจะตอบว่า
`ขออภัย เกิดข้อผิดพลาดในการแปล ลองใหม่อีกครั้ง` และเขียน error ลง log แทนการ crash

## โครงสร้างไฟล์

```
.
├── index.js                        # จุดเริ่มต้น: สร้าง bot, ลงทะเบียน handler, launch
├── package.json
├── .env.example                    # ตัวอย่างตัวแปรสภาพแวดล้อม (ห้ามใส่ค่าจริง)
├── .gitignore                      # กัน node_modules/, .env และ data/
├── config
│   └── whisper-vocabulary.js       # คำศัพท์ใบ้ Whisper แยกตามภาษาปลายทาง
├── data/                           # สร้างอัตโนมัติตอนรัน ไม่ถูก commit
│   └── user-languages.json         # ภาษาปลายทางของแต่ละ chat_id
└── src
    ├── config.js                   # อ่านค่าจาก .env และตรวจสอบความถูกต้อง
    ├── languages.js                # รายการภาษาที่รองรับ + เทียบรหัสภาษา
    ├── store
    │   └── language-store.js       # อ่าน/เขียนภาษาที่เลือกลงไฟล์ JSON
    ├── services
    │   ├── http.js                 # ลองยิงใหม่ 1 ครั้งเมื่อ timeout/เน็ตสะดุด
    │   ├── typing.js               # แสดง "กำลังพิมพ์" และส่งซ้ำระหว่างรอ
    │   ├── whisper.js              # เรียก OpenAI Whisper (whisper-1)
    │   └── translate.js            # เรียก Google Translation v2 (แปล + ตรวจภาษา)
    └── handlers
        ├── index.js                # รวบรวมและลงทะเบียน handler ทั้งหมด
        ├── start.js                # คำสั่ง /start
        ├── reaction.js             # react ❤ ทันทีที่ได้รับข้อความเสียง
        ├── language-select.js      # ปุ่มเลือกภาษา, /cl, ด่านตรวจก่อนแปล
        └── translate.js            # ถอดเสียง + แปลไป-กลับ
```

การเพิ่มฟีเจอร์ใหม่ทำได้โดยสร้างไฟล์ใน `src/handlers/` ที่ export ฟังก์ชัน
`register(bot)` แล้วเพิ่มเข้าไปในลิสต์ `handlers` ใน `src/handlers/index.js`

> **ลำดับการลงทะเบียนสำคัญ:** `language-select` ต้องมาก่อน `translate` เพราะทำหน้าที่
> เป็นด่านตรวจ — ถ้าแชทยังไม่เคยเลือกภาษาจะถามแล้วหยุดไว้ ถ้าเลือกแล้วจึงเรียก
> `next()` ส่งต่อให้ `translate`

## การติดตั้งและใช้งาน

ต้องใช้ Node.js เวอร์ชัน 18 ขึ้นไป

```bash
# 1. ติดตั้ง dependencies
npm install

# 2. สร้างไฟล์ .env จากตัวอย่าง
cp .env.example .env

# 3. ใส่ token ที่ได้จาก @BotFather ลงในไฟล์ .env
#    TELEGRAM_BOT_TOKEN=123456:ABC-DEF...

# 4. รันบอท
npm start
```

ระหว่างพัฒนาใช้ `npm run dev` เพื่อให้ Node รีสตาร์ทอัตโนมัติเมื่อไฟล์เปลี่ยน

## ตัวแปรสภาพแวดล้อม

| ตัวแปร | จำเป็น | คำอธิบาย |
| --- | --- | --- |
| `TELEGRAM_BOT_TOKEN` | ✅ | Token ของบอทจาก [@BotFather](https://t.me/BotFather) |
| `OPENAI_API_KEY` | ✅ | ใช้กับ Whisper สำหรับถอดเสียงเป็นข้อความ |
| `GOOGLE_TRANSLATE_API_KEY` | ✅ | Google Cloud Translation API v2 (แปล + ตรวจภาษา) |

ถ้าไม่มี `TELEGRAM_BOT_TOKEN` บอทจะหยุดทำงานทันทีพร้อมข้อความบอกวิธีตั้งค่า
ส่วนอีกสองตัวถ้าไม่มีบอทยังเริ่มได้แต่จะเตือนใน log และฟีเจอร์แปลจะตอบว่าเกิดข้อผิดพลาด

## ความปลอดภัย

- **ห้าม** commit ไฟล์ `.env` หรือใส่ token / API key จริงลงในโค้ดเด็ดขาด
- `.gitignore` กัน `.env` และ `node_modules/` ไว้แล้ว
- หาก token หลุดออกไป ให้ revoke ทันทีผ่าน `/revoke` ที่ @BotFather
